O app usa o número do cliente selecionado ou digitado. Texto vai direto para a conversa. Para imagem, o WhatsApp não permite, pelo navegador, anexar mídia automaticamente para um número específico. Nesse caso, o app gera o card, copia o texto e abre a conversa certa para você anexar o card.
